## 📂 Proyectos

**[gestor-gastos-poo](https://github.com/AxelAgreda/gestor-gastos-poo)**
Modelo en Python, con programación orientada a objetos, de una app de gastos compartidos. Tiene una clase abstracta con cuatro tipos de movimiento (gasto, ingreso, ahorro y retiro), composición, agrupación, excepciones propias y montos con `Decimal` para evitar errores de redondeo.

**App de gastos compartidos** *(Google Apps Script + Google Sheets)*
Aplicación web para el celular que permite registrar un gasto en segundos. Tiene un dashboard con gráficos, una pestaña de ahorros, comparación entre usuarios, administración de categorías y una API REST conectada a los Atajos de Apple.

**Herramientas para operaciones de contact center**
Dashboards de desempeño con cálculo de bonos, reportes de asistencia que generan archivos para Recursos Humanos y la automatización de la distribución mensual de agentes entre líderes de equipo con Apps Script.
